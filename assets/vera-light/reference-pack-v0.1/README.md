## Происхождение и границы

Автор генераций: ИИ по запросу владельца VERA LIGHT, встроенный image_gen.
Каждый из шести кадров получен отдельно из одного исходного Telegram-изображения.
Точные запросы сохранены в [PROMPTS.md](PROMPTS.md). Seed и версия базовой модели инструментом не предоставлены.
Исходник сохранён отдельно; генерации его не заменяют.
Серьги-компасы добавлены при генерации, а не взяты из исходника. Комплект с этим украшением акцептован пользователем.

Это шесть акцептованных визуальных кадров, а не согласованная 3D-модель и не готовый видеоаватар.
Ракурсы, отсутствующие в исходнике, являются генеративной интерпретацией.
Одинаковый prompt не гарантирует идентичные результаты в разных генераторах.
Технический набор строгих профилей пока не готов.

## Визуальный аудит

Сохранены общий типаж, бирюзовая среда, спокойная мимика и естественная текстура кожи.
Надписи удалены из новых кадров. Все шесть новых изображений просмотрены.
Между кадрами меняются рисунок цифровых линий, мелкая геометрия серёг, эмблема и отдельные пропорции лица.
Верхний запас кадра и угол поворота неодинаковы. Кадр по пояс предлагает длинные рукава и светлый низ — это не утверждённый канон одежды.

Первичная проверка до акцепта: HOLD для производственного видео; кандидаты пригодны для обсуждения.
Решение владельца от 2026-09-10: «Все супер Акцепт GO» — визуальный комплект v0.1 принят.
Технический допуск к производственному видео остаётся HOLD до теста анимации.
Нельзя обещать отсутствие мерцания деталей при анимации на основании статичных изображений.

## E2E, ответственность и следующий шаг

Исходник → варианты → сравнение → акцепт одного master владельцем →
согласование деталей → подготовка недостающих строгих профилей →
короткая тестовая анимация → проверка лица, губ, серёг и линий в движении.

Владелец образа утверждает лицо и украшение. Редактор проверяет согласованность.
Сервис анимации не определяет канон автоматически.
Использование: подбор ведущей, тест прямого обращения, выбор поворота для сцены.
Набор не является автоматическим разрешением на публикацию.

Новые итерации сохраняются отдельной версией. При неудаче возврат к исходнику или
последнему акцептованному master; текущие изображения не перезаписываются.
Голос, эмоции, деталь украшения, канальные сцены и анимация в этот набор не входят.
