Назначение: цикл статей для дискуссионного клуба «РЫНОК НЕДВИЖИМОСТИ 2030» и будущих передач VERA LIGHT

Статьи объясняют рынок широкой аудитории и не являются техническими заданиями.
Каждая статья может быть источником серии выпусков VERA LIGHT. Связь фиксируется
в каноническом реестре: статья → ветка дерева → вопросы выпусков.
Каждая статья проходит путь:

```text
дискуссия → системный разбор → критика → статья → акцепт → commit
```

считается окончательно принятым клубом.
