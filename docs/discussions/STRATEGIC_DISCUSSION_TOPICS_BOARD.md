# ТАБЛО ТЕМ СТРАТЕГИЧЕСКОГО КЛУБА

## РЫНОК НЕДВИЖИМОСТИ 2030

Назначение: единый список тем, вопросов и результатов дискуссионного клуба.

Правило движения:

```text
тема
→ системный разбор
→ критическая проверка
→ фиксация выводов
→ статья для YouTube
→ акцепт
→ commit
```

Статусы:

- `PLANNED` — запланировано;
- `IN_DISCUSSION` — обсуждается;
- `DRAFT_ARTICLE` — готовится статья;
- `ACCEPTED` — принято в клубе;
- `ARCHIVED` — зафиксировано и закрыто;
- `OPEN` — вопрос остаётся нерешённым.

## Формат завершения темы

Каждая тема должна закончиться:

1. главным тезисом;
2. системной картой;
3. фактами и гипотезами;
4. скрытыми предположениями;
5. рисками и возражениями;
6. возможным экспериментом;
7. статьёй для YouTube;
8. решением об акцепте и фиксации.

## Ближайшая последовательность

```text
1. завершить разбор устойчивости классического агентства
2. сравнить самостоятельного агента-оператора и гибридную модель
3. определить, что именно получает агент от BENJA
4. определить, за что платит клиент
5. построить денежный и ответственный контур
6. подготовить и акцептовать YouTube-статью
```
