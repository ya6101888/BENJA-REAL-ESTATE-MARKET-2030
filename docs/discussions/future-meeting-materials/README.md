# Материалы для будущих заседаний клуба

Здесь собираются статьи, тезисы и исследовательские материалы, которые
предложены для рассмотрения на одном из будущих заседаний, но пока не включены
в утверждённую повестку конкретного заседания.

Материал в этой папке не считается принятым решением клуба, утверждённой статьёй
или частью текущей повестки. Номер заседания и номера статей присваиваются только
после отдельного решения владельца клуба.
