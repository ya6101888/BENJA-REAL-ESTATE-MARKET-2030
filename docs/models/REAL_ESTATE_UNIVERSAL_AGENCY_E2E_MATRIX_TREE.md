# Универсальное агентство недвижимости: E2E-матрица и дерево производственного процесса

Статус: рабочая модель стратегической дискуссии  
Фокус: жилая недвижимость России, с отдельным вниманием к Ростову-на-Дону  
Назначение: описание основной функции агентства и полного производственного бизнес-процесса E2E

## Основная функция агентства

Главная производственная функция агентства недвижимости:

> Превратить жилищную задачу клиента в безопасную, согласованную и завершённую сделку с подходящим объектом.

```text
Потребность клиента
→ подходящий объект
→ проверенное решение
→ согласованные условия
→ оформленная сделка
→ переданный результат
→ пост-сделочная память
```

## 2. Ключевые входы процесса

- жилищная задача клиента;
- объект или требования к объекту;
- бюджет;
- документы;
- ипотечные условия;
- сроки;
- информация с платформ;
- сведения продавца;
- локальный контекст;
- данные специалистов.

## 3. Ключевые выходы процесса

- найденный или реализованный объект;
- согласованные условия;
- проверенный пакет документов;
- завершённая сделка;
- переданный объект;
- полученная комиссия;
- удовлетворённый клиент;
- сохранённая история сделки.

## 4. Главный результат

Главный результат агентства — не договор и не комиссия.

```text
Главный результат
= подходящий объект
+ приемлемый риск
+ согласованные условия
+ завершённая передача
+ пригодность решения для клиента
```

Комиссия является коммерческим результатом, но не полным результатом услуги.

## 6. Пять результатов работы агентства

```text
1. Клиентский результат
   Подходящее жилищное решение.

2. Транзакционный результат
   Завершённая и оформленная сделка.

3. Коммерческий результат
   Комиссия и прибыль агентства.

4. Информационный результат
   Обновлённая база объектов, клиентов и сделок.

5. Репутационный результат
   Отзыв, повторная сделка и рекомендация.
```

Слабое агентство останавливается на третьем результате — получении комиссии. Сильное агентство должно управлять всеми пятью.
